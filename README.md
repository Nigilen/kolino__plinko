# 🎱 Plinko

Интерактивная **физическая симуляция Plinko** на Pixi.js с кастомной реализацией механики падения и столкновений.

🔗 **Демо**: [https://nigilen.github.io/kolino__plinko/](https://nigilen.github.io/kolino__plinko/)

---

### 💡 Особенности

- **Кастомная физика без сторонних библиотек** — реализация гравитации, коллизий и отскоков «с нуля» на чистом Pixi.js для глубокого понимания физических процессов.  
- **Конфигурируемая сцена** — все параметры (размеры, позиции пинов, гравитация, отскок) вынесены в типизированный конфиг, что позволяет быстро менять геймплей без правки кода.  
- **Модульная архитектура** — логика проверки коллизий, разрешения столкновений и анимации разделена на независимые функции, что упрощает тестирование и расширение.  
- **Адаптивный рендеринг** — корректное отображение на любых экранах благодаря логическим координатам сцены и автоматическому масштабированию.  
- **Система ячеек с множителями** — поддержка нескольких зон захвата внизу с разными коэффициентами для игровой механики.

> ⚠️ **Важно**: Проект изначально создавался с целью **практики анимирования физики падения и столкновений**. Именно поэтому используется исключительно Pixi.js без подключения сторонних физических движков (Matter.js, Planck.js и др.). Это усложняет разработку, но даёт полный контроль над каждым аспектом симуляции и глубокое понимание того, как работает игровая физика «под капотом».

---

### 🛠 Технологии

- **Pixi.js** — рендеринг и работа с дисплеем  
- **TypeScript** — строгая типизация конфига и физических функций  
- **HTML5 / CSS3 / JavaScript** — базовая структура и стили  
- **Vite** — сборка и dev-сервер  
- **Figma** — дизайн макета и графических элементов

---

### ▶ Как запустить локально

1. Устанавливаем зависимости:
```bash
npm install
```

2. Запускаем dev-сервер:
```bash
npm run dev
```
---

### 🎯 Для чего этот проект

- **Образовательная цель**: глубокое погружение в физику 2D-движения, векторную математику и обработку коллизий без «магии» сторонних библиотек.  
- **Портфолио**: демонстрация способности реализовывать сложные интерактивные механики на чистом WebGL через Pixi.js.  
- **База для игр**: архитектура готова к расширению — можно добавить звуки, частицы, систему очков или сетевой мультиплеер.

---

> Проект создан как учебный полигон для отработки навыков low-level анимации и физики в вебе. Здесь нет «костылей» и готовых решений — только чистый код, математика и контроль над каждым кадром. Именно такой подход позволяет не просто «сделать», а **понять**, как работает интерактивная графика. 🚀
